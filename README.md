📊 Layihə Məqsədi
Bu layihə e-ticaret şirkətinin satış performansını, müştəri davranışını və məhsul trendlərini analiz etmək üçün tam həyat dövrü analitik həll təqdim edir. Layihə SQL sorğularından başlayaraq, Excel vizuallaşdırmaları və PowerPoint təqdimatı ilə tamamlanır.

🎯 Əsas Məqsədlər
Satış performansının dəyərləndirilməsi - gəlir, mənfəət və satış trendlərinin təhlili
Müştəri davranışının öyrənilməsi - segmentasiya, sadiqlik və alış qaydaları
Məhsul performansının təhlili - ən çox satılan və ən çox qazanc gətirən məhsullar
Problem sahələrinin müəyyən edilməsi - qaytarmalar, ləğv edilən sifarişlər və endirim təsiri
📋 Proyektin Strukturu
Layihə üç əsas mərhələdən ibarətdir:

1. SQL İlə Məlumatların Təhlili
Verilənlər bazasında SQL sorğuları vasitəsilə satış məlumatlarının təhlili və müxtəlif metrikaların hesablanması.

2. Excel İlə Vizuallaşdırma
SQL nəticələrinin Excel-ə ixrac edilməsi və pivot cədvəllər, qrafiklər və dashboard yaradılması.

3. PowerPoint İlə Təqdimat
Tapıntıların və tövsiyələrin strukturlaşdırılmış şəkildə təqdim edilməsi.

🗄️ Verilənlər Bazası Strukturu
Proyekt aşağıdakı 5 əsas cədvəldən istifadə edir:

Cədvəl	Təsvir	Əsas Məlumatlar
CUSTOMERS	Müştəri məlumatları	Müştəri profili, yaş, şəhər, qeydiyyat tarixi
PRODUCTS	Məhsul məlumatları	Məhsul adı, kateqoriya, qiymət, maya dəyəri
ORDERS	Sifariş məlumatları	Sifariş tarixi, ödəniş üsulu, status
ORDER_DETAILS	Sifariş detalları	Miqdar, endirim, məhsul-sifariş əlaqəsi
RETURNS	Qaytarma məlumatları	Qaytarma səbəbi, tarixi
📊 Analiz Tapşırıqları
I. Satış Performansı Metrikaları
1. Ümumi Satış Məbləği
Məqsəd: Şirkətin ümumi satış gəlirini hesablamaq
Metod: Hər sifarişdəki məhsulun qiymətini miqdarla vurub, endirimi çıxmaq
Nəticə: Tamamlanmış bütün sifarişlərin ümumi gəliri

2. Aylıq Satış Təhlili
Məqsəd: Zamanla satış trendlərini müşahidə etmək
Metod: Hər ay üçün sifariş sayı və satış məbləğini hesablamaq
Nəticə: Ay üzrə satış həcmi və sifariş statistikası

3. Məhsul Gəlirliliyi
Məqsəd: Hər məhsulun gəlir, xərc və mənfəətini təhlil etmək
Metod: Hər məhsul üçün gəlir (satış qiyməti × miqdar) və mənfəət (gəlir - maya dəyəri) hesablamaq
Nəticə: Məhsulların gəlirlilik sıralaması və mənfəət marjası

4. Top 5 Məhsul
Məqsəd: Ən çox gəlir gətirən məhsulları müəyyən etmək
Metod: Məhsulları ümumi gəlirə görə sıralamaq və ilk 5-i seçmək
Nəticə: Prioritizasiya edilmiş məhsul siyahısı

5. Top 5 Müştəri
Məqsəd: Ən dəyərli müştəriləri müəyyən etmək
Metod: Müştəriləri ümumi xərclənən məbləğə görə sıralamaq
Nəticə: VIP müştərilərin siyahısı

6. Şəhərlər Üzrə Satış
Məqsəd: Coğrafi baxımdan satış performansını təhlil etmək
Metod: Hər şəhər üçün sifariş sayı və satış məbləği hesablamaq
Nəticə: Şəhər üzrə satış payları

II. Endirim və Ödəniş Analizi
7. Endirimin Təsiri
Məqsəd: Endirim kampaniyalarının effektivliyini qiymətləndirmək
Metod: Endirimli və endirimsiz sifarişlərin orta qiymətini və sifariş həcmini müqayisə etmək
Nəticə: Endirim strategiyasının effektivlik dərəcəsi

8. Ödəniş Üsullarının Payı
Məqsəd: Müştərilərin ödəniş üsullarına olan meyillərini başa düşmək
Metod: Hər ödəniş üsulu üçün satış payını hesablamaq
Nəticə: Ödəniş üsullarının populyarlıq dərəcəsi

9. Ləğv Edilmiş Sifarişlər
Məqsəd: Ləğv problemlərinin miqyasını qiymətləndirmək
Metod: Ləğv edilmiş və tamamlanmış sifarişlərin nisbətini hesablamaq
Nəticə: Ləğv faizi və potensial problem sahələri

III. Qaytarma Analizi
10. Qaytarma Faizi
Məqsəd: Ümumi qaytarma səviyyəsini ölçmək
Metod: Qaytarılan sifarişlərin ümumi sifarişlərə nisbətini hesablamaq
Nəticə: Ümumi qaytarma dərəcəsi

11. Ən Çox Qaytarılan Məhsullar
Məqsəd: Problemli məhsulları və kateqoriyaları müəyyən etmək
Metod: Hər məhsul və kateqoriya üçün qaytarma sayını hesablamaq
Nəticə: Yüksək qaytarma dərəcəsi olan məhsullar

12. Qaytarma Səbəbləri
Məqsəd: Qaytarmaların əsas səbəblərini başa düşmək
Metod: Qaytarma səbəblərinin payını hesablamaq
Nəticə: Problem səbəblərinin prioritizasiyası

IV. Bonus Təhlillər
13. Kateqoriya Üzrə Mənfəət Marjı
Məqsəd: Hər kateqoriyanın gəlirlilik səviyyəsini qiymətləndirmək
Nəticə: Ən gəlirli və ən az gəlirli kateqoriyalar

14. Yaş Qrupları Üzrə Satış
Məqsəd: Müxtəlif yaş qruplarının alış davranışını təhlil etmək
Nəticə: Hədəf auditoriyanın müəyyən edilməsi

15. İllik Artım Təhlili
Məqsəd: 2023 və 2024-cü illər arasında satış artımını qiymətləndirmək
Nəticə: Büdcə planlaşdırması üçün artım proqnozu
